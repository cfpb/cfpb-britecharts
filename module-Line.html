Line

Line Chart reusable API module that allows us rendering a multi line and configurable chart.
Description:
  • Line Chart reusable API module that allows us rendering a multi line and configurable chart.
Source:
  • line.js, line 107
Tutorials:
  • Tutorial: line
Example
let lineChart = line();

lineChart
    .aspectRatio(0.5)
    .width(500);

d3Select('.css-selector')
    .datum(dataset)
    .call(lineChart);
