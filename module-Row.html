Row Chart reusable API class that renders a simple and configurable row chart.
Description:
  • Row Chart reusable API class that renders a simple and configurable row chart.
Source:
  • row.js, line 55
Tutorials:
  • Tutorial: row
Example
var rowChart = row();

rowChart
    .height(500)
    .width(800);

d3Select('.css-selector')
    .datum(dataset)
    .call(rowChart);
